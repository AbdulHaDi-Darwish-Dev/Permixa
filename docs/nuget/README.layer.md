# Permixa layer packages

This package is part of **Permixa IAM** for ASP.NET Core.

Most applications should install the primary entry package only:

```bash
dotnet add package Permixa.AspNetCore --prerelease
```

`Permixa.Domain`, `Permixa.Application`, and `Permixa.Infrastructure` are supporting packages. They are brought in transitively and are mainly useful for advanced scenarios or direct references.
